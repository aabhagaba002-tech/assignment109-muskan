📝 Assessment Questions & Answers

Question 1Remembering · Knowledge

List four primary characteristics of a modern digital computer and identify the key hardware technology associated with each of the five generations of computers.

Answer 1: Characteristics and Generations

Four characteristics of a modern digital computer:

  1. Speed: Performs millions or billions of operations per second.
  2. Accuracy: Produces precise results when the input and instructions are correct.
  3. Storage: Stores large amounts of data and retrieves it quickly.
  4. Diligence and consistency: Repeats tasks without fatigue and gives consistent results.

Five generations of computers:

  • First generation Vacuum tubes; large, hot machines with high power consumption.
  • Second generation Transistors; smaller, faster and more reliable systems.
  • Third generation Integrated circuits (ICs); improved speed and reduced size.
  • Fourth generation Microprocessors using VLSI technology; personal computers became widespread.
  • Fifth generation ULSI, parallel processing and AI-oriented technologies; emphasis on intelligent systems.
Question 2Understanding · Comprehension

Explain the flow of data, instructions, and control signals within the functional block diagram of a computer, detailing the interaction between the CPU, memory unit, and I/O interface.

Answer 2: Functional Block Diagram and Data Flow

A computer system consists of an input unit, memory, the Central Processing Unit (CPU), an output unit and connecting buses.

  • Input unit: Accepts data and instructions from devices such as a keyboard or scanner and converts them into a machine-readable form.
  • Memory unit: Holds programs, input data, intermediate results and final results. RAM provides temporary working storage.
  • CPU: The Control Unit (CU) fetches and decodes instructions; the Arithmetic Logic Unit (ALU) performs arithmetic and logical operations; registers hold small amounts of fast-access data.
  • I/O interface: Connects peripheral devices to the system, manages device-specific signals and helps transfer data.
  • Output unit: Presents processed results through a monitor, printer, speaker or another output device.

Flow: Input data enters through an I/O interface, is stored in memory, and is fetched by the CPU. The CU sends control signals, the ALU processes data, and results are stored in memory or sent to an output device. The address bus identifies locations, the data bus carries data, and the control bus carries read/write and timing signals.

Basic sequence: Input → Memory ↔ CPU (CU + ALU + Registers) → Memory → Output
Question 3Applying · Application

Demonstrate how optical data scanning devices (e.g., barcode/OMR scanners) and electronic card readers (e.g., RFID/smart card readers) can be deployed in a campus environment to automate student attendance and library checkouts.

Answer 3: Campus Automation Using Scanners and Card Readers

Scanning devices and electronic card readers reduce manual work, speed up record keeping and improve accuracy.

  1. Barcode or QR attendance: Each student receives a unique printed ID. At entry, the scanner reads the code and the system records student ID, date, time and class.
  2. OMR for forms: Optical Mark Recognition can read marked bubbles on standardized forms, such as surveys or attendance sheets designed for OMR.
  3. RFID attendance: A student taps an RFID-enabled ID card near a reader. The system verifies the ID and logs attendance automatically.
  4. Smart-card library checkout: The card identifies the student, while a barcode or RFID tag identifies the book. The library system records the issue date, due date and return status.

Benefits: Faster service, fewer data-entry errors, searchable records and easier report generation.

Precautions: Protect student data, restrict access to authorized staff, provide a manual backup, and prevent duplicate or fraudulent scans.

Question 4Analyzing · Analysis

Distinguish between low-level languages (Machine and Assembly) and high-level languages in terms of execution speed, hardware dependence, translation requirements, and programming complexity.

Answer 4: Low-Level vs High-Level Languages

  • Low-level languages: Machine language uses binary instructions; assembly language uses mnemonics such as MOV and ADD. They are closely linked to a processor's architecture.
  • High-level languages: Use more human-readable statements, such as Python, Java and C++. They are generally easier to develop, read and maintain.

Question 5Analyzing · Analysis

Compare point-and-draw devices (such as a mouse and trackball) with graphics digitizers/drawing tablets, highlighting how their coordinate tracking mechanisms and operational sensitivity differ for CAD and digital art applications.

Answer 5: Pointing Devices vs Graphics Tablets

  • Mouse: Tracks relative movement across a surface using an optical sensor. It is suitable for selecting icons, menus and general computer work.
  • Trackball: The device stays stationary while the user rotates a ball. It is useful where desk space is limited.
  • Graphics tablet/digitizer: A stylus moves over a sensitive surface. It can map stylus position to screen coordinates and may detect pressure, tilt and sometimes rotation.

Coordinate tracking: A mouse and trackball generally report relative movement; a graphics tablet can provide precise absolute coordinates within its active area.

Sensitivity and applications: A mouse is effective for everyday tasks and many CAD interface operations. A tablet offers finer stylus control, pressure sensitivity and natural strokes, making it well suited to digital illustration, handwriting and detailed design. For CAD, the best choice depends on the required precision and workflow; a tablet does not automatically replace a mouse in every task.

Question 6Evaluating · Evaluation

Assess whether a drum/flatbed plotter or an ultra-high-definition large-format printer combination is superior for producing civil engineering blueprints, justifying your selection based on line resolution, scalability, and long-term production costs.

Answer 6: Plotter vs Large-Format Printer

For most modern civil-engineering offices, an ultra-high-definition large-format printer is the more practical choice for routine blueprint production, while a traditional plotter can still be useful for specialized vector work.

  • Line resolution: Modern large-format printers can produce sharp fine lines, text, hatching and shaded drawings. Output quality depends on printer resolution, ink, paper and settings.
  • Scalability: Large-format printers commonly support different roll widths and paper sizes, making A1/A0 drawings and plans convenient to produce.
  • Production speed: Printers generally handle mixed content—lines, text, images and filled areas—efficiently. Traditional pen plotters may be slower for complex drawings.
  • Long-term cost: Consider purchase price, ink or pens, paper, maintenance, service availability and volume. A modern printer is often easier to integrate into existing CAD workflows.
Recommendation: Choose a large-format printer for most day-to-day blueprint work. A specialized plotter may be justified when its specific line-drawing capabilities or existing workflow outweigh its operating and maintenance costs.
Question 7Evaluating · Evaluation

Critique the operational reliability and security vulnerabilities of vision-input devices (facial recognition) compared to voice recognition devices when deployed as primary biometric authentication tools in high-ambient-noise, publicly exposed environments.

Answer 7: Facial Recognition vs Voice Recognition

Neither technology is completely reliable or secure in every public environment. The best choice depends on lighting, noise, privacy needs and the threat model.

  • Facial recognition — reliability: Works without speaking and can be convenient, but poor lighting, camera angle, masks, image quality and changes in appearance may reduce accuracy.
  • Facial recognition — security: It may be attacked using photographs, videos or masks if effective liveness detection is absent. Camera-based identification also raises privacy and surveillance concerns.
  • Voice recognition — reliability: Background noise, reverberation, illness, microphone quality and changes in voice can reduce accuracy. High ambient noise is a major disadvantage.
  • Voice recognition — security: Recordings, synthesized voices and replay attacks may fool weak systems. Voice samples are also sensitive biometric data.

Conclusion: In a noisy public setting, facial recognition may be more operationally reliable than voice recognition if lighting and camera placement are suitable. However, it should use liveness checks, encryption, limited data retention and a non-biometric alternative. For important access, combine biometrics with a card or PIN rather than relying on a single factor.

Question 8Creating · Synthesis

Design an accessible, hands-free computer workstation tailored for a visually impaired user. Propose a coherent integration of non-visual input devices (such as voice recognition systems and tactile keyboards) with specialized output devices (such as voice response synthesizers and screen readers).

Answer 8: Accessible Hands-Free Workstation

The workstation should allow the user to operate a computer independently through speech, tactile controls and audio feedback.

  1. Voice input: A microphone with noise reduction and speech-recognition software enables dictation, opening applications and voice commands.
  2. Tactile keyboard: A keyboard with raised home-row markers or Braille labels supports accurate touch typing. A Braille display can provide refreshable tactile text.
  3. Screen reader: Software such as NVDA or VoiceOver reads menus, documents, web pages and alerts aloud, with keyboard navigation support.
  4. Speech synthesizer: Text-to-speech converts screen-reader output into spoken feedback through headphones or speakers.
  5. Accessible display and controls: High-contrast settings, scalable text, clear focus indicators and keyboard-accessible software support users with partial vision.
  6. Privacy and backup: Provide headphones, local processing where practical, secure voice-data handling, and a way to use the computer if the microphone or internet fails.

Working sequence: The user speaks or types → the computer processes the command → the screen reader announces the result → the user confirms the next action by voice or tactile input.

Expected outcome: Greater independence, reduced reliance on visual cues, safer navigation and more inclusive access to education and work.
